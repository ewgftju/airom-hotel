# AIROM Hotel

Официальный сайт гостиницы AIROM Hotel в Атырау.

**Сайт:** https://airom-hotel.vercel.app

## Основные разделы

- номера и оснащение;
- питание для команд;
- условия для команд и организаций;
- галерея;
- стоимость и бронирование;
- контакты и маршрут в 2GIS.

Сайт разработан на Next.js и адаптирован для размещения на Vercel.

## Локальный запуск

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run start
```
